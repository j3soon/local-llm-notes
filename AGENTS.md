# Repository Instructions

## Commits

- Include a commit body describing relevant technical changes.
- Agent-created commits need a descriptive body ending with a `by <Harness> (<Model>)` line using the actual harness and model names, e.g. `by Codex (gpt-5.6-sol)` or `by Claude Code (Opus 5)`.

## Documentation

- Keep READMEs concise, simple, and readable. Describe the current setup and behavior; omit replaced implementations, migration history, and chronological debugging notes.
- Document useful findings and primary references alongside the relevant configuration or instructions. Keep detailed validation reports separate from setup documentation.
